# Deep Space Intelligence Briefing: Omicron Ceti (Mira)

Omicron Ceti is a classic symbiotic binary system located approximately 300 light-years from Earth. 

## System Architecture
- **Mira A:** A pulsating Asymptotic Giant Branch (AGB) red giant.
- **Mira B:** A compact, hot white dwarf orbiting at roughly 70 AU.
